# การนำเข้าตารางเรียนทั้งภาคการศึกษา

ระบบรับไฟล์ CSV แบบ UTF-8 ขนาดไม่เกิน 2 MB โดยหนึ่งแถวแทนตารางเรียนที่เกิดซ้ำทุกสัปดาห์ ระบบจะตรวจรูปแบบข้อมูล ห้อง อาจารย์ ช่วงภาคเรียน และเวลาชนก่อนบันทึก

หากมีแถวใดไม่ถูกต้อง ระบบจะยกเลิกทั้งไฟล์และไม่เก็บข้อมูลเพียงบางส่วน

## คอลัมน์

| คอลัมน์ | ตัวอย่าง | ความหมาย |
|---|---|---|
| `course_code` | `CPE221` | รหัสรายวิชา |
| `course_name` | `ปฏิบัติการฐานข้อมูล` | ชื่อรายวิชา |
| `section` | `1` | กลุ่มเรียน |
| `room_code` | `CPE-101` | รหัสห้องที่มีอยู่ในระบบ |
| `lecturer_email` | `lecturer@lums.local` | อีเมลอาจารย์ที่มีสิทธิ์ใช้งาน |
| `day_of_week` | `1` | 1=จันทร์ ถึง 7=อาทิตย์ |
| `starts_time` | `09:00` | เวลาเริ่ม รูปแบบ 24 ชั่วโมง |
| `ends_time` | `12:00` | เวลาสิ้นสุด |
| `active_from` | `2026-08-03` | วันแรกที่เริ่มใช้ตาราง |
| `active_until` | `2026-11-20` | วันสุดท้ายที่ใช้ตาราง |
| `notes` | `งดสัปดาห์สอบ` | หมายเหตุ ไม่บังคับ |

ดาวน์โหลดไฟล์ตัวอย่างจากหน้า **ตารางเรียน → นำเข้าตารางทั้งเทอม** เพื่อรักษาชื่อและลำดับคอลัมน์ให้ถูกต้อง
